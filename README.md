# All-In-One Discord Bot

Ein leistungsstarker, modularer Bot für Discord Communities.

## Features
- **Commands**: Umfangreiches Slash-Command System
- **Events**: Automatisierte Reaktionen auf Server-Aktivitäten
- **Database**: Integriertes Datenbanksystem
- **Handlers**: Modularer Aufbau für Commands, Events und Interactionen
- **Docker**: Containerisiert für einfaches Deployment
